# 個人信件資安防護外掛 (Personal Email Security Plugin)

這是一個基於 Google Apps Script 開發的個人化信件安全防護工具。透過自動化的網址掃描機制，協助使用者在點擊電子郵件內的未知連結前，預先攔截潛在的社交工程與釣魚攻擊。

## 💡 開發動機

在現今的職場環境中，社交工程攻擊層出不窮。許多資安事故的起因，往往是員工收到偽裝成客戶寄來的信件（例如夾帶惡意 SharePoint 連結的 Outlook 信件），點擊後不僅導致個人帳戶遭到盜用，更可能成為內部廣發釣魚信件的跳板，引發連鎖的資安危機。

為了提升個人的資安防護力，並填補日常收發信件時的盲區，我決定主動開發這款輕量級的防護外掛。期望透過自動化的威脅情資比對，在風險發生前提供清晰的預警。

## ✨ 核心功能

* **自動化連結擷取**：自動解析信件內容，提取出所有可點擊的 URL 連結。
* **雙重威脅情資掃描**：
    * 串接 **VirusTotal API**：進行全方位的惡意網址與網域信譽檢查。
    * 串接 **AlienVault OTX API**：利用開源威脅情資平台，進一步確認連結是否涉及已知的惡意活動或攻擊指標 (IoC)。
* **直覺的風險提示**：當掃描到可疑連結時，提供明確的警告與可點擊的查詢報告連結，協助使用者做出安全的判斷。

## 🛠 技術架構

* **開發語言**：JavaScript / Google Apps Script (GAS)
* **整合應用**：Google Workspace (Gmail)
* **第三方 API**：
    * VirusTotal API
    * AlienVault OTX (Open Threat Exchange) API

## 🚀 部署與使用方式

1. 將本專案的原始碼部署至您的 Google Apps Script 專案中。
2. 於指令碼屬性 (Script Properties) 中設定您的 API 金鑰：
   * `VT_API_KEY`：填入您的 VirusTotal API Key
   * `OTX_API_KEY`：填入您的 OTX API Key
3. 儲存並授權執行權限後，即可在個人信箱中啟用此防護功能。

## 📂 專案結構

* `Code.gs`：核心業務邏輯，包含信件解析與觸發機制。
* `Scanner.gs`：負責串接 VirusTotal 與 OTX API，處理非同步請求與回傳資料解析。
* `UI.html`：前端使用者介面（若有實作側邊欄或提示視窗）。

## 🛡️ 注意事項與未來展望

此專案為個人資安實踐的開端。目前的設計確保了分析過程不會洩漏個人機密資訊，所有 API 金鑰均妥善保存在後台環境變數中。未來計畫進一步優化掃描效能，並擴充更多威脅情資來源，以應對日益複雜的網路攻擊手法。
